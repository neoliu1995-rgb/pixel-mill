### 1.2.2 国际化方案

采用自研轻量级i18n方案（`src/lib/i18n.ts` + `LanguageProvider`组件），支持中英文切换。翻译键按模块组织（如`pricing.*`、`dashboard.subscription.*`），通过`useLanguage()` Hook获取翻译函数。

> **通俗解释**：i18n是"internationalization"的缩写（i和n之间有18个字母），指让软件支持多国语言。我们的方案是在一个文件里定义所有翻译文本，页面根据用户选择的语言显示对应文本。

### 1.3.2 认证流程

采用**双重认证机制**：

1. **NextAuth.js (JWT策略)**：用于页面级会话管理，用户登录后颁发JWT令牌，存储在Cookie中
2. **自定义JWT (jsonwebtoken)**：用于API级认证，登录接口颁发独立JWT令牌

> **通俗解释**：JWT（JSON Web Token）是一种无状态认证方式。用户登录成功后，服务器生成一个加密的"通行证"（Token）发给客户端，客户端后续请求携带此通行证，服务器验证通行证即可确认身份，无需在服务器端存储会话信息。

认证辅助函数`getCurrentUser(request)`从NextAuth会话中提取当前用户信息，并联合查询Subscription表获取用户套餐等级，所有需要认证的API路由统一调用此函数。

## 1.4 数据库方案

### 1.4.1 数据库选型

采用**SQLite**作为数据库，通过**Prisma ORM**访问。

> **选型理由**：
> - SQLite是零配置的嵌入式数据库，整个数据库就是一个文件，部署极简
> - 适合中小规模SaaS（日活<10万），读写性能足够
> - 后续可平滑迁移至PostgreSQL（Prisma支持切换数据源）
>
> **通俗解释**：传统数据库（如MySQL）需要单独安装和运行一个"数据库服务器"程序，而SQLite直接把数据库存为一个文件，程序读写这个文件即可，非常适合快速开发和小型应用。

## 1.5 AI模型集成方案

### 1.5.1 Provider架构设计

采用**策略模式（Strategy Pattern）**设计AI模型Provider层，通过统一接口抽象不同AI服务的差异。

> **通俗解释**：策略模式就像"万能充电器"——不同手机有不同的充电接口（Lightning/USB-C/Micro-USB），万能充电器提供统一的外部接口，内部自动适配不同接口。同样，我们的Provider层对外提供统一的`generate()`方法，内部自动适配Gemini/SiliconFlow/阿里百炼等不同AI服务的API。

### 1.5.2 智能路由策略

Router层根据以下维度自动选择最优模型：

1. **用户等级过滤**：Free用户仅可使用free tier模型，Pro用户可使用free+pro模型，Business用户可使用全部模型
2. **中文检测**：当提示词中文字符占比>20%时，优先选择支持中文的模型（如通义万相、Gemini）
3. **质量优先排序**：在可用模型中按quality评分降序选择
4. **降级回退**：首选模型失败后依次尝试其他Provider，最终回退到Pollinations（免费、无需API Key）

## 1.7 安全方案

### 图表 1-10：安全措施清单

| 安全措施 | 实现方式 | 保护目标 |
|----------|----------|----------|
| **密码安全** | bcrypt哈希（自带盐值，10轮加密） | 防止密码泄露 |
| **会话安全** | JWT令牌（7天有效期） | 无状态认证 |
| **支付限流** | IP级速率限制（10次/分钟） | 防止暴力攻击 |
| **输入校验** | sanitizeCheckoutInput() | 防止参数注入 |
| **金额验证** | validatePaymentAmount() | 防止金额篡改 |
| **Webhook验签** | Stripe签名验证/支付宝RSA2/微信AES-GCM | 防止伪造回调 |
| **JWT密钥** | 环境变量强制配置，无硬编码回退 | 防止密钥泄露 |

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  用户访问  │───▶│  注册页面  │───▶│ 提交注册  │───▶│ 创建用户  │

                                                     ▼
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  访问功能  │◀──│ 获得JWT  │◀──│ 验证密码  │◀──│ 创建免费  │
│  页面     │    │ 令牌     │    │ bcrypt   │    │ 订阅     │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                      ▲
┌──────────┐    ┌──────────┐          │
│  登录页面  │───│ 提交登录  │──────────┘
```

**关键节点说明**：
1. 注册时使用bcrypt对密码进行哈希加密，数据库中不存储明文密码

4. 所有需要认证的API通过`getCurrentUser()`验证JWT并获取用户信息
